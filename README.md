# KelanaAI - AI Travel Planner

KelanaAI is an AI-powered travel assistant built with Python, Next.js, and Amazon Bedrock.

## Session 01 - Feature: Trip Summary Generator (Console App)
This session establishes the core project structure and implements the interactive CLI trip summary generator.

### Folder Structure
- `backend/`: Python backend and business logic
- `frontend/`: Next.js frontend application (reserved for Session 6+)

### How to Run
```bash
cd backend
python main.py
